# EH — analiza rentowności

Lokalny model Streamlit do analizy kosztów, przychodów i rentowności spraw EH.

## Instalacja

```bash
python -m venv .venv
```

Aktywuj środowisko wirtualne odpowiednio do systemu operacyjnego, a następnie:

```bash
pip install -r requirements.txt
```

## Uruchomienie

```bash
streamlit run app.py
```
